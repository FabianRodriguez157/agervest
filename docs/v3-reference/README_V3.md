# AgerVest Web — versión orientada a usuario final

## Abrir rápido
Abre `index.html`. No necesitas instalar nada.

## Login funcional sin servidor
El registro e inicio de sesión funcionan con `localStorage`. Cuentas incluidas:
- inversionista@agervest.pe / Demo1234
- productor@agervest.pe / Demo1234
- aliado@agervest.pe / Demo1234

Cada perfil abre un panel diferente.

## Analítica
Los usuarios registrados pueden consultar gráficos de precios, producción, rendimiento y referencias regionales generados a partir de los archivos incorporados de MIDAGRI, SENAMHI y Seguro Agrícola Catastrófico.

## PostgreSQL opcional
Se incluye `database/agervest_postgresql.sql` y un backend Express en `backend/`. La web puede presentarse sin configurarlo. Consulta `backend/README_BACKEND.md`.

# Fuentes integradas

## Archivos incorporados
1. MIDAGRI — Cuadros en Excel del boletín *El Agro en Cifras* Julio 2026.
2. Seguro Agrícola Catastrófico — Consolidado de campañas agrícolas.
3. SENAMHI — Variables meteorológicas de estaciones automáticas.
4. Valor de jornal.
5. Precio de alquiler de tractor.
6. Precio de yunta.
7. Producción / importación de fertilizantes (archivo disponible como referencia para ampliaciones posteriores).

## Uso en la interfaz
- Superficie cosechada, producción, rendimiento y precio al productor se tomaron de los archivos de MIDAGRI.
- La siniestralidad regional se tomó del consolidado del Seguro Agrícola Catastrófico.
- Los costos operativos regionales se aproximaron con jornal, tractor y yunta.
- El clima regional se contextualizó con variables de estaciones automáticas de Arequipa.
